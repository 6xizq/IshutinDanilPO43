# Danil Ishutin | Software Engineering Student
📍 Shchuchinsk, Kazakhstan

Hi! I'm a software engineering student at the Higher Technical College. This repository is a collection of my college assignments, personal projects, and random code experiments. I mainly code in C#, but I also work with Python, Lua, and databases.

## 💻 Tech Stack
* **Languages:** C#, SQL, Python, Lua
* **Frameworks & UI:** .NET, WinForms, Entity Framework Core, Cosmos
* **Databases:** MS SQL Server, SQLite

## 📂 What's inside?

* **CryptoTestnet**
  A custom blockchain node and testnet built from scratch in C#. I wrote this to understand how hashing, transaction validation, and mempools actually work under the hood.

* **TaliOS**
  A micro operating system based on the Cosmos framework. It runs directly on hardware without a host OS. It features a custom command-line shell with a history buffer and a Virtual File System (VFS) to read files directly from the drive. 

* **GameStoreProject & SmartMarket**
  Desktop apps for store management and sales automation. Built using C# WinForms and Entity Framework for database operations. Includes user authentication, shopping carts, and receipt generation.

* **OsuSessionTracker**
  A small utility tool I made for tracking session data and playtime in *osu!*.

*(Side note: I also won a Silver Medal at WorldSkills Aqmola 2025 in 1C:Enterprise programming).*

## 🌱 Currently Learning
I'm actively trying to write cleaner code, learning system design, and moving from basic WinForms apps to scalable Web APIs using modern .NET.

## 📂 Что внутри?

* **CryptoTestnet**
  Кастомная нода блокчейна и тестовая сеть, написанная с нуля на C#. Делал этот проект, чтобы разобраться, как под капотом работают хеширование, валидация транзакций и мемпул.

* **TaliOS**
  Микро-ОС на базе фреймворка Cosmos. Запускается на железе без Windows/Linux. Написал для неё кастомную консоль (с буфером истории команд) и прикрутил виртуальную файловую систему (VFS) для чтения файлов прямо с диска.

* **GameStoreProject & SmartMarket**
  Десктопные приложения для автоматизации продаж и управления магазином. Написаны на C# WinForms + Entity Framework для работы с БД. Есть авторизация, логика корзины и генерация чеков.

* **OsuSessionTracker**
  Небольшая утилита, которую я написал для трекинга игровой статистики и времени сессий в *osu!*.
